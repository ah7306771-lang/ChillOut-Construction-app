# نظام النسخ الاحتياطي (Backup System)

المجلد ده بيتحدث اتوماتيك كل يوم عن طريق GitHub Actions.
كل نسخة احتياطية بتتحفظ في مجلد بتاريخها: `backups/YYYY-MM-DD/`.

---

## 📅 مواعيد التشغيل

- **اتوماتيك:** كل يوم الساعة **3 صباحاً بتوقيت القاهرة** (00:00 UTC).
- **يدوي:** من تبويب Actions → Daily Backup → Run workflow.

---

## 📦 محتويات كل نسخة احتياطية

كل مجلد `backups/YYYY-MM-DD/` بيحتوي على:

| الملف | الوصف |
|---|---|
| `APP.xlsx` | شيت البيانات الرئيسي (المصدر لأوامر البيع والأسعار) |
| `allSales.json` | كل أوامر البيع (السعر / العميل / التاريخ) |
| `checks.json` | بيانات الشيكات (الفواتير المستحقة) |
| `salaries.json` | بيانات المرتبات |
| `parties.json` | بيانات الأطراف / العملاء |
| `overdue.json` | الفواتير المتأخرة |
| `lastPrices.json` | آخر أسعار الشراء والبيع |
| `attendanceStatus.json` | بيانات الحضور |
| `dataUpdatedAt.json` | timestamp آخر تحديث للبيانات |
| `manifest.json` | manifest تبع الـ PWA |
| `index.html` | كود التطبيق الكامل |
| `firebase-messaging-sw.js` | Service worker للإشعارات |
| `scripts/` | سكريبتات بايثون + كود VBA (`.bas`) |
| `README.md` | فيه commit hash + قائمة بكل الملفات في النسخة دي |

---

## 🔄 كيفية الاسترجاع (Restore)

### استرجاع ملف واحد:

1. افتح `backups/YYYY-MM-DD/` بتاريخ النسخة اللي عايزها.
2. اضغط على الملف المطلوب → **Raw** → **Save as...**
3. ارفعه بدل الملف الحالي في الـ root عن طريق:
   - GitHub Web: افتح الملف الأصلي → ✏️ Edit → امسح المحتوى → الصق المحتوى من النسخة → Commit.
   - أو Upload file → Replace.

### استرجاع كامل (Rollback الكود):

لو عايز ترجّع الكود لحالته وقت باكب معين:

```bash
# اعرف الـ commit اللي كان وقت النسخة
cat backups/YYYY-MM-DD/README.md

# ارجع لنقطة ما قبل المشكلة
git revert <commit-hash>
git push
```

### استرجاع الجوجل شيت (Apps Script):

- كود الـ Apps Script موجود snapshot منه في: `backups/apps-script/` *(هيتضاف قريباً)*.
- بيانات الجوجل شيت هتتصدر JSON مع كل باكب يومي *(هيتضاف قريباً)*.

---

## 🧹 سياسة الاحتفاظ (Retention)

- كل نسخة أقدم من **30 يوم** بتتمسح اتوماتيك.
- الغرض: تجنب تضخم حجم الريبو.
- لو عايز تحتفظ بنسخة محددة للأبد، انقلها في مجلد `backups/archive/YYYY-MM-DD/` يدوياً.

---

## ⚙️ ملف الـ Workflow

- المكان: [`.github/workflows/daily-backup.yml`](../.github/workflows/daily-backup.yml)
- الصلاحيات: `contents: write` (عشان يعمل commit للنسخة).
- Concurrency: run واحد بس في نفس الوقت (`daily-backup` group).

---

## 📱 ملفات غير مغطاة بالباكب ده

الملفات اللي بره الريبو محتاجة نسخة احتياطية منفصلة:

1. **`D:\IRON GATE\بيانات التوريد.xlsm`** (على جهازك)
   - **الحل المقترح:** فعّل OneDrive أو Google Drive على مجلد `D:\IRON GATE`.
   - كده أي تعديل بيتحفظ اتوماتيك على السحابة مع version history.

2. **Google Apps Script code** (اللي مربوط بالجوجل شيت)
   - **الحل المقترح:** إضافة `exportBackup` action + snapshot يومي لكود السكريبت داخل الباكب.
   - هيتم في مرحلة تانية لو الحضرتك موافقة.

---

## 🚨 في حالة الطوارئ

لو التطبيق وقف أو حصلت مشكلة:

1. روح على `backups/` وشوف آخر نسخة سليمة.
2. قارن `dataUpdatedAt.json` عشان تعرف آخر تحديث للبيانات.
3. لو المشكلة في الكود: راجع Commits وارجع لنقطة قبل التعديل الغلط.
4. لو المشكلة في البيانات: استرجع ملف JSON المحدد من النسخة السليمة.
